# 城市集中供热寒潮协同仿真系统

在寒潮过程中协调热源能力、管网温度、泵站压力、建筑热惯性与分区需求,
支持值守操作、根因分析、多策略对照与迟报数据补算。纯 Python 标准库, 无第三方依赖。

## 快速开始

```bash
python3 -m district_heating.cli compare    # 同一寒潮过程下多策略对照
python3 -m district_heating.cli diagnose   # 值守操作扰动的根因分析
python3 -m district_heating.cli backfill   # 迟报数据补算与重新评估
python3 -m unittest discover -s tests      # 运行测试
```

## 系统能力

- **管网输运延迟**: 每条管段为带延迟线的活塞流模型, 热量经管网后按距离
  延迟到达各区域, 并伴有沿程散热 (`district_heating/network.py`)。
- **值守操作**: 改变热源出力、调整支路流量、临时降低非关键区域供应
  (关键区域降供会被拒绝), 操作按时刻调度 (`actions.py`)。
- **根因分析**: 压力波动回溯到具体操作; 回水温度异常区分流量过大与
  供热不足; 区域持续低温沿"降供 → 支路流量 → 热源能力 → 管网温降"
  因果链定位, 输出根因而非裸告警 (`diagnosis.py`)。
- **策略对照**: 被动/预测协同等多种策略在同一气象过程(相同随机种子)
  下运行, 按关键区低温时长、压力波动、回水异常等 KPI 对比 (`strategy.py`)。
- **迟报补算**: 仿真按检查点存档, 迟报数据到达后回滚重放受影响时段,
  重新计算 KPI 与根因 (`backfill.py`)。

## 模型概要

| 环节 | 模型 |
|------|------|
| 气象 | 分段寒潮曲线 + 日波动 + 可复现随机扰动 |
| 热源 | 出力上限、爬坡速率约束、供水温度热惯性、过载时供水温度被拉低 |
| 管网 | 活塞流延迟线 + 沿程散热; 泵站压力 = 扬程 − k·流量² |
| 建筑 | 分区一阶 RC 热惯性, 风速修正散热系数, 关键/非关键优先级 |
